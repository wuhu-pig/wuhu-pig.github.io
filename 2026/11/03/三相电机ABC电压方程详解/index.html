相电压方程详解

先明确 ABC 三相相电压方程，再从磁链、电感、反电动势的物理来源推导，最后用真实时间轴观察转速改变频率，以及三相每个电压分量如何叠加。

贯穿全文的主线：同一个磁链导数，解释电感项和反电动势项

这里用“磁链变化 → 感应电压”的被动电压参考方向；法拉第定律中的负号会在第 04 节解释。

先看本篇重点 / ABC 相电压三相电压方程到底是在描述什么？

先规定参考方向：三相星形接法；iA、iB、iC 均从各自端子流向中性点 N；uAN = vA − vN、uBN = vB − vN、uCN = vC − vN。这样每一相都可写出一条电压平衡式。

uAN = R·iA + Leq·diA/dt + eA
uBN = R·iB + Leq·diB/dt + eB
uCN = R·iC + Leq·diC/dt + eC

这是线性、对称、电感不随位置变化、无中性线的简化模型，不是适用于所有电机的无条件公式。更一般的原式是 uabc = Rabc·iabc + dψabc/dt。

图 0：ABC 三条方程是三个端口的电压平衡，而不是“电机三相电压永远是正弦波”的断言。实际相电压还取决于电流波形、转速、控制策略与逆变器。
式子的物理含义

R·i：铜绕组耗能形成压降。
L·di/dt：相电流改变磁链所需的电压。
e：转子永磁磁链随时间改变带来的感应电压。

两个关键约束

对于无中性线三相 Y 接：
iA + iB + iC = 0
若线性对称、永磁三相磁链平衡：
eA + eB + eC = 0

00 / 阅读地图先把六个容易混淆的概念分开

i

电流

单位 A。电荷定向运动；绕组的电流可以产生磁场。

B

磁感应强度

单位 T。描述空间某位置磁场的方向与强弱。

Φ

磁通

单位 Wb。穿过某个指定面积的磁场“总量”。

ψ

磁链

单位 Wb·匝（匝通常视作无量纲）。考虑每一匝被多少磁通穿过。

L

电感

单位 H。描述电流变化时，磁链随电流变化的程度。

e

反电动势

单位 V。永磁转子运动使定子磁链变化而产生的感应电压。

最关键的区分：磁链 ψ 是某一时刻的状态量；dψ/dt 是该磁链变化在端口电压方程中的感应项（采用被动电压参考方向）。有磁链不等于一定有感应电压，必须有时间变化。

01 / 看得见的物理直觉导线通电，为什么就有磁场？

通电导线的周围存在环绕导线的磁场。把导线绕成很多匝，就得到线圈；各匝产生的磁场在空间叠加，线圈内部可以出现相对集中的磁场。再加上铁芯（低磁阻路径），就能让更多磁通经过我们希望的位置。

图 1：电流 → 磁场 → 线圈磁场叠加 → 铁芯磁路。图是帮助建立物理直觉的示意，不是三相电机实际槽型或精确的磁力线分布。

为什么电机绕组要绕很多圈？一个重要原因是：同样的电流，更多匝数可以提供更大的磁动势，近似写为 F = N·i，N 是匝数。实际效果还受铁芯、气隙、饱和与漏磁影响。

记忆锚点：电流不是“凭空制造出电感”，而是通过磁场与绕组磁链建立联系。电感是这层联系的定量描述。

02 / 磁场如何变成数学量磁通 Φ 与磁链 ψ：两者到底差在哪？

2.1 磁通：先选一块面积，问有多少磁场穿过去

磁通的定义是：磁感应强度 B 在某一选定曲面上的通量。如果磁场均匀、表面是平面，就可以简化成：

Φ = B · A · cos(α) ，单位 Wb

其中 α 是磁场方向与面积法线的夹角。磁场垂直穿过平面时，磁通绝对值最大；磁场平行于平面时，磁通为零。一般情况应写为面积积分 Φ = ∫ B·dA。

图 2：磁通不是“磁场的另一种叫法”；它必须相对于一个选定面积才有意义。

2.2 磁链：一匝磁通与 N 匝磁通的区别

一根绕一圈的导线，如果有磁通 Φ 穿过这一圈，就有一个绕组的磁通关联。现在把导线绕成 N 圈，如果每一匝都链接到同样的磁通，则：

ψ = NΦ

更普遍地写，是所有匝各自所链接磁通的总和：ψ = Φ₁ + Φ₂ + … + Φₙ。所以 磁链 ψ 的大小不仅取决于磁场，也取决于绕组如何摆放、多少匝链接到它。

1 匝：ψ = Φ
100 匝（理想）：ψ = 100Φ

磁链有两种常见来源，需要严格区分。注意“电流产生的磁链”和“电感”不是一回事：电感是二者间的比例或局部增量关系：

  • 定子电流产生的磁链：线圈通电，磁场穿过绕组本身或其它相绕组。
  • 转子永磁体产生的磁链：即使定子不通电，只要转子带有永磁体，其磁场仍可能穿过定子绕组。
特别重要：定子电流为 0，不代表总磁链为 0。永磁体可以单独提供磁链。反过来，磁链不变化时，也不意味着会产生感应电压。

03 / 最常觉得抽象的一项电感 L 不是一个“神秘元件”，而是磁链与电流的关系

3.1 从一根线圈推导电感

为了容易理解，先假设磁路不饱和、没有永磁体、漏磁忽略。磁路可用一个“磁阻” ℜ 来近似。绕组 N 匝、电流 i 产生磁动势 N·i：

Φ ≈ Niℜ　→　ψ = NΦ ≈ N²iℜ

两边比较得到：

ψ = Li　　，　　L ≈ N²ℜ

这就解释了电感的来源：绕组的匝数、结构、铁芯材料、气隙、磁路几何决定电流能建立多少磁链。绕组匝数一般越多、磁阻越低，电感越大（在这个简化磁路中）。

但是在电机里，电感不总是常数：铁芯饱和后，磁链对电流的增量可能变小；IPMSM 的不同转子方向也会有不同的磁阻与电感。对于非线性磁链曲线，控制时更要关注微分电感 L_inc = dψ/di，而不能只用 ψ/i。

3.2 为什么电感会“阻碍电流变化”？

电流一变 → 它建立的磁场跟着变 → 磁链跟着变 → 按法拉第定律，线圈两端出现感应电压。这个电压的极性倾向于抵抗导致它的变化（楞次定律）。

uL = dψdt = L didt　（L 为常数，采用被动电压方向）

从这条式子读出三种情况：

电流状态di/dt电感两端电压 uL物理含义
正在迅速增加正、且大正、且大需要电压来建立磁场、增加磁能
保持恒定00（理想 L）磁能仍存在，但不再因电流变化而需电感压降
正在迅速减小负、且大负、且大磁场释放能量，倾向于维持原电流方向

注意：说“电感阻碍电流变化”是对现象的简写。电感并不总是让电流变小，而是不允许电流毫无代价地瞬间突变。例如突然断开电感回路时，为了保持电流连续，它可能产生很高的电压。

3.3 电感把能量存在哪里？

理想线性电感存储磁场能量：

Wmag = 12Li²

想象推一辆有惯性的手推车：你要花力气让它加速，已经运动的推车也不愿瞬间停下。电感的类似点在于“对变化的抵抗”，但不是机械惯性本身；在电感里，储存的是磁场能量。

对电机控制特别有用的一点：电阻 R 使能量以热耗散；理想电感 L 在磁场中存储和释放能量。所以快速电流控制关心 L，而铜耗与温升关心 R。

04 / 第二个关键直觉反电动势 e 是怎么“生”出来的？

4.1 不通电的线圈，为什么转动磁铁也能测出电压？

考虑一只固定线圈，旁边放一块永磁体。当磁铁不动时，穿过线圈的永磁体磁链保持不变；当磁铁转动或移动时，穿过线圈的磁链随时间变化。变化的磁链本身就能产生电压，不要求线圈内先有电流。

图 3：磁铁与线圈的相对位置变化会改变磁链。图中用磁铁转动示意；真正三相电机是定子绕组固定、转子磁极转动。

法拉第定律写成感应电动势的回路方向时：

ℰ = − dψdt

负号表达楞次定律：感应电动势的方向使其效应反抗磁通变化。可是为什么电机电压方程中写 + dψ/dt？因为一个是沿选定回路正向的感应电动势，另一个是在电流流入电压正端的被动参考方向下的端口感应电压项。二者参考方向不同；只要方向定义始终一致，物理内容相同。

4.2 反电动势为什么通常与速度成正比？

对理想正弦 PMSM，设 A 相永磁磁链为：

ψfA = ψm cos(θe)

转子运动使电角度 θe 随时间变化。对时间求导，使用链式法则：

eA = dψfAdt = −ωeψm sin(θe)

其中 ωₑ = dθₑ/dt 是电角速度，单位 rad/s。因而相反电动势的峰值：

Epeak = |ωe| ψm

同一台电机、磁链幅值近似不变时，转速翻倍，反电动势峰值也近似翻倍。需要注意单位：如果电机有 p 对极，ωₑ = p·ωₘ，不是直接把机械 rpm 代入 rad/s 的公式。

4.3 为什么叫“反”电动势？

在电动运行（motoring）时，转子受电磁转矩驱动，绕组中因转子旋转产生的感应电压，一般表现为抵消施加电压中用于驱动电流的余量，所以称为“反电动势”。这是电磁能量转换的表现：电压、电流与机械转矩和转速相关联。

但不能理解为“反电动势在所有时刻都和电源电压方向相反”。三相交流瞬时量会改变符号；发电、再生制动工况下，它还可以成为向外送出能量的原因之一。

零速的关键区别：即使永磁体的磁链 ψf 很大，转子静止且磁场不随时间变化时，dψf/dt = 0，旋转反电动势为 0。因此基于反电动势的常规无感估算在零速附近尤其困难；高频注入等方法另当别论。

05 / 现在开始推公式三项电压到底怎样出现在同一个方程中？

5.1 先写最通用的一相方程

取定子 A 相绕组，电流 iA 从 A 端流入，N 是星形中性点；uAN 是 A 端相对 N 的电压。假设绕组电阻为 R、磁链为 ψA，那么端口电压的基本关系为：

uAN = R iA + dψAdt

这是整篇笔记最值得背下来的一行。它不是靠“把电阻、电感和一个电源串起来”强行拼出来的，而是绕组的电阻压降 + 法拉第感应项。

5.2 将磁链拆成电流引起的部分和永磁体引起的部分

为先建立直觉，假设电感线性且位置不变，并把相间互感合并为一个合适的等效电感：

ψA = L iA + ψfA

两边对时间求导：

dψAdt = L diAdt + dψfAdt

定义反电动势 eA = dψfA/dt，代回方程：

uAN = RiA + LdiAdt + eA
图 4：单相等效电路。R、L、e 是不同物理机制在端口方程中的等效表示；实际电机三相还存在互感与位置相关性。

5.3 用一个数字例子，看三项各分了多少电压

假设某时刻 A 相：uAN = 7.5 V，R = 0.2 Ω，iA = 5 A，L = 0.5 mH，eA = 6 V。那么：

diAdt = 7.5 − 0.2×5 − 60.0005 = 1000 A/s

物理含义：这一瞬间绕组电流以 1 A/ms 的变化率上升，不意味着它会永远保持这个斜率。因为电流、反电动势或输入电压的变化都会改变斜率。

06 / 扩展到三相ABC 的三个方程，为何还要考虑互感？

6.1 星形连接是什么，电压到底以哪里为参考？

图 5：三相 Y 接。示意图只展示连接关系，不代表实际相绕组在电机内部的几何形状。

如果三相星形连接且中性点不外接电流通路，基尔霍夫电流定律给出：

iA + iB + iC = 0

这就是为什么实际控制中可以测两相电流后推算第三相电流：iC = −iA − iB。

6.2 最完整的三相电压方程先不要急着写成 Li

uAN = RiA + dψA/dt
uBN = RiB + dψB/dt
uCN = RiC + dψC/dt

这里每相磁链不仅由该相电流决定，也受其它两相电流及转子永磁体影响：

ψA = LAA·iA + LAB·iB + LAC·iC + ψfA(θe) ψB = LBA·iA + LBB·iB + LBC·iC + ψfB(θe) ψC = LCA·iA + LCB·iB + LCC·iC + ψfC(θe)

LAA 是自感，LAB 是 B 相电流对 A 相磁链的互感，ψfA 是永磁体对 A 相的磁链。三个方程整体写为：

u_abc = R · i_abc + dψ_abc/dt ψ_abc = L(θe, i) · i_abc + ψf(θe)

其中 L 是 3×3 电感矩阵；在磁饱和时，这样的线性乘积表示本身只是近似，较一般的磁链映射应写成 ψ_abc = ψ_abc(iA, iB, iC, θe)。

6.3 在哪些假设下，才能退化为最简单的三相方程？

假设三相对称、各相自感相同为 Ls、任意相间互感均为 M、所有这些电感不随转子角度变化，并且无中性线：

ψA = Ls·iA + M·iB + M·iC + ψfA = Ls·iA + M·(−iA) + ψfA = (Ls − M)·iA + ψfA

因此定义等效相电感 Leq = Ls − M，就得到熟悉的简化模型：

uAN = RiA + Leq·diA/dt + eA
uBN = RiB + Leq·diB/dt + eB
uCN = RiC + Leq·diC/dt + eC

原来 ABC 方程中的那个 L，并不必然等于“单根绕组孤立测得的自感”。互感在对称条件下已被吸收到等效电感里。

6.4 三相反电动势为什么相差 120°？

对理想正弦气隙磁链、对称三相绕组，三相绕组轴线在空间相隔 120° 电角度，因此永磁体磁链与其时间导数也会有 120° 的相位差。仍用第 04 节的 cos 定义：

ψfA = ψm·cos(θe) ψfB = ψm·cos(θe − 2π/3) ψfC = ψm·cos(θe + 2π/3) eA = −ωe·ψm·sin(θe) eB = −ωe·ψm·sin(θe − 2π/3) eC = −ωe·ψm·sin(θe + 2π/3)

理想正弦平衡条件下，eA + eB + eC = 0。现实 BLDC 若反电动势为近似梯形，就不能直接把正弦式套用到它的每一时刻。

6.5 更进一步：如果电感还随转子位置改变？

如果电感矩阵依赖 θe，那么对 L(θe)·i 求导不能只留下 L·di/dt；还会出现：

u = Ri + L didt + ωe ∂L∂θe i + ωe ∂ψf∂θe

这是位置相关、线性电感矩阵模型的展开式。凸极 PMSM（常有 Ld ≠ Lq）就很需要考虑这一现象。初学时先牢牢记住 u = Ri + dψ/dt，这样以后遇到更复杂的电机模型也不会迷路。

核心章节 / ABC 相电压深入分析ABC 三相电压如何计算、怎样在实际电机上理解？

A. 从“相绕组端口”严格推导 ABC 三条方程

用统一符号：iabc = [iA, iB, iC]ᵀ，uabc = [uAN, uBN, uCN]ᵀ。不论反电动势是否正弦，最先成立的绕组电压形式是：

uAN = RA·iA + dψA/dt uBN = RB·iB + dψB/dt uCN = RC·iC + dψC/dt

对于三相电阻相同、磁链关于电流线性，且自感和互感不随转子位置变化的理想对称电机：

ψA = Ls·iA + M·iB + M·iC + ψfA(θe) ψB = M·iA + Ls·iB + M·iC + ψfB(θe) ψC = M·iA + M·iB + Ls·iC + ψfC(θe)

Y 接且中性点悬空时，由 iA+iB+iC=0，例如 A 相的电流磁链部分变为 Ls·iA + M(iB+iC)=(Ls−M)iA。于是 Leq=Ls−M、eA=dψfA/dt，三相电压方程就得到开头的简化式。

为什么一定要写出推导假设？因为 IPMSM 的电感矩阵会随角度变化，饱和时还会随电流变化。此时把电感视为常数直接算 Leq·di/dt 会遗漏位置项、非线性项；应回到更一般的 u = Ri + dψ/dt。

B. 正弦 PMSM 示例：A 相、B 相、C 相电流与反电动势

下面的交互实验专门采用一个可验证的教学假设：三相电流与各自永磁体反电动势同相，以展示电动能量转换；这里选用 ψfA = ψm·cosθe，所以 eA = −ωe·ψm·sinθe，同时令 iA = −Ipk·sinθe。B、C 相分别将角度平移 −120°、+120°。

iA = −Ipk sinθe
iB = −Ipk sin(θe − 120°)
iC = −Ipk sin(θe + 120°)

因此 A 相 diA/dt = −Ipk·ωe·cosθe，把三项代入：

uAN = −(RIpk + ωeψm)sinθe − (LeqIpkωe)cosθe

B、C 相只需把 θe 分别替换成 θe−120° 和 θe+120°，即得到 uBN 和 uCN。这个特殊例子不是所有控制工况通用的电流波形；更一般情况应保留每相的实际电流及其导数。

C. 相电压、线电压、桥臂电压——三者不能画等号

对于三相 Y 接电机，以逆变器直流母线负极 O 为参考：

桥臂电压：uAO = vA − vO 相电压： uAN = vA − vN = uAO − uNO 线电压： uAB = vA − vB = uAN − uBN = uAO − uBO

在理想对称、无中性线、三相电流总和为零、无零序内部感应电压的模型下，将三相相电压方程相加可得 uAN+uBN+uCN=0，于是：

uNO = (uAO + uBO + uCO) / 3

所以可从三个桥臂电位重构相电压，例如：

uAN = [2uAO − uBO − uCO] / 3
图 7：逻辑示意，O 是直流负端，N 是电机星形中性点。图中线条不代表实际安全测试接法；实际测量必须考虑 PWM 高频共模与探头安全。

这就是为什么“示波器在 A 桥臂测到 12 V”不能直接代入 uAN=12 V。使用高频 PWM 时，还要区分开关瞬时电压与电流模型通常使用的PWM 周期平均/等效电压。如有零序、非对称、共模寄生电流等，重构式需要重新审视。

D. 工程分析 ABC 电压方程时的四个检查

  1. 量纲：Ri 为 V，L·di/dt 为 H·A/s = V，e=ωψ 为 rad/s·Wb = V。
  2. 方向：三相电压、相电流、磁链正方向必须统一，否则 e 和 L·di/dt 的符号可能看似反了。
  3. 三相平衡：iA+iB+iC=0 不代表 uAO+uBO+uCO=0；不要混淆相电压与桥臂电压。
  4. 数学模型边界：非正弦 BLDC、磁饱和、位置相关电感、非理想逆变器都需要更一般的磁链模型或相应修正。

08 / 联系真实嵌入式开发这个方程，怎样用到 BLDC / PMSM 控制中？

8.1 电流环：电压决定电流斜率

对简化等效单相模型重排：

didt = u − Ri − eL

这说明电流变化速度由剩余电压决定：施加电压减去电阻压降，再减去相应反电动势。电流环调 PWM，本质是通过逆变器施加电压，让绕组电流按目标轨迹变化。

8.2 无感估算：已知电压电流，能否反推 e？

e ≈ u − Ri − L didt

原则上可以。实际项目中，PWM 开关噪声、电压死区、母线电压、采样偏置、参数温漂、逆变器压降、电流微分噪声等都会导致估算误差。FOC 常在 αβ 坐标系中构造状态观测器，而非对 ADC 采样电流直接做裸微分。

对六步换相 BLDC，还经常利用未通电相的反电动势过零点估算换相时机。但“三相全部在 PWM 驱动”的 FOC，不能照搬该方法。Microchip 无感位置估算说明。

8.3 模型离散化：方程怎样进 MCU 的 C 代码？

假设采样周期 Ts 足够短，使用前向欧拉近似：

i[k+1] ≈ i[k] + TsL(u[k] − R·i[k] − e[k])

最简单的教学版浮点实现：

/* 教学用途：单相简化模型，非可直接投产的控制算法 */
typedef struct {
    float resistance_ohm;
    float inductance_h;
    float current_a;
} PhaseModel;

void model_step(PhaseModel *m,
                float phase_voltage_v,
                float back_emf_v,
                float ts_s)
{
    const float di_dt = (phase_voltage_v
                        - m->resistance_ohm * m->current_a
                        - back_emf_v)
                        / m->inductance_h;
    m->current_a += ts_s * di_dt;
}

真实三相实现必须额外处理相间耦合、等效相电压重构、采样同步、PWM 非理想性和参数边界。特别是离散积分的稳定性与采样周期有关，不能让 Ts 任意增大。

8.4 FOC 为什么还要 Clarke / Park 变换？

因为三相 ABC 的电压、电流是相互耦合的交流量；在合适的正弦 PMSM 模型下，变换为 αβ 静止坐标，再转到 dq 同步旋转坐标，可把平衡的正弦电流变成相对稳定的直流分量，更便于使用 PI 电流环。ABC 模型是基础，dq 模型不是凭空出现的另一套物理定律。

09 / 工程上最容易踩的坑常见误区：为什么算出来和测出来不一致？

容易误解的说法应该怎么理解
“有磁链，就有反电动势”错。要有永磁磁链随时间变化才有对应的旋转反电动势。
“电流是 0，所以磁链是 0”错。永磁体提供的磁链仍可能存在。
“电感电压等于 Li”错。固定 L 下为 L·di/dt，Li 对应的是电流建立的磁链。
“电感 L 总是不变”错。磁饱和和转子位置可能改变增量电感，特别是凸极电机。
“三相没有互感”错。简化方程里的 Leq 可能已经包含对称互感的影响。
“示波器桥臂对地电压就是相电压”错。相电压要相对于电机中性点 N 定义；桥臂对直流母线负端是另一个量。
“电角度横轴看不出速度变化，所以速度没有影响频率”错。以电角度为横轴固定 360°，永远是一个电周期；观察变快必须改用固定时间轴。
“机械转速 rpm 等于电频率 Hz”错。fe = p·rpm/60，p 是极对数；ωe = 2πfe。不能混淆极数与极对数。
“转速翻倍，线圈磁链必然翻倍”错。理想永磁体磁链幅值近似不变，翻倍的是角速度与感应电压峰值。
“所有 BLDC 反电动势都可以按正弦写”错。需要看实际电机的反电动势波形与模型假设。
“线电阻与相电阻、电感读数可以无条件等同”错。星形端子间测量包含两相绕组，互感、接线与测量频率也会影响电感读数。
台架安全提示：三相逆变器桥臂是高速开关节点，普通台式示波器探头的地夹通常与保护地相连。不要把地夹随意夹到浮动相线或桥臂开关节点上；应使用适当额定等级的差分探头与安全测量方案。

10 / 随时打开复习五分钟复习卡 + 9 道自测题

磁链 ψ与绕组各匝链接的磁通总和；同磁通、同 N 匝时 ψ = NΦ。

闭卷试一试（点击展开答案）

Q1：永磁体不动、定子相电流恒定，绕组中可能有磁链吗？会有感应电压吗？

可能有磁链，来自永磁体和定子电流。但若整个磁链不随时间变化，则对应的磁链导数为 0，理想情况下没有这部分感应电压；绕组电阻仍有 Ri 压降。

Q2：为什么 ψ = Li，而 uL = L·di/dt？

ψ = Li（线性假设）表示电流建立多少磁链；uL = dψ/dt 表示建立或减小磁链时需要的电压。常数 L 下求导才得到 L·di/dt。

Q3：转速翻倍，理想正弦 PMSM 的 e 峰值和电频率怎样变化？

如果永磁磁链 ψm 基本不变，Epeak=|ωe|ψm，电频率 fe=p·n/60；两者都翻倍。固定时间轴的周期数翻倍，固定电角度轴仍只展示一个周期。

Q4：为什么 iA + iB + iC = 0？所有三相系统都成立吗？

无中性线的星形接法、忽略寄生泄漏路径时，由中性点的 KCL 得到。若中性线引出并有电流、或存在显著共模寄生电流，不能无条件使用。

Q5：电机三相互感存在，为什么简单公式里只有 L？

在三相对称、自感 Ls 和互感 M 常数、三相电流之和为 0 的条件下，可以把互感合并为 Leq = Ls − M。超出这些假设就需要使用电感矩阵或更一般的磁链映射。

Q6：示波器看到 A 相桥臂对直流母线负极是 12V，能直接说 uAN=12V 吗？

不能。uAN = vAO − vNO。中性点可能浮动，开关波形和 PWM 平均值也要区分。

Q7：为什么反电动势为零时，不代表无感启动根本不可能？

因为“常规基于旋转反电动势的估算失效”不等于全部无位置传感算法失效。对于适合的电机与硬件，还可能用高频注入等利用凸极特性的技术；也有开环启动与切换策略。

Q8：理想平衡时 uAN + uBN + uCN = 0，是否意味着 uAO + uBO + uCO 也恒等于 0？

不是。桥臂电压与相电压由中性点电位联系：uAN=uAO−uNO。对称、无零序时 uNO=(uAO+uBO+uCO)/3；PWM 零矢量和共模变化尤其明显。

Q9：电频率 133.33 Hz，30 ms 会画出几周期？

fe·Δt=133.33×0.03≈4 个电周期；固定角度轴 0°～360° 永远显示一个周期。

后续学习的最佳顺序

  1. 先彻底弄懂 ψ、L、e 的来源。 不靠背诵，能画出磁链变化产生电压的因果关系。
  2. 再看 ABC 三相星形与相间互感。 熟练解释为什么两相电流可以推第三相，以及何时成立。
  3. 学习 Clarke / Park 变换。 从 abc → αβ → dq，解释为什么控制电流更方便。
  4. 进入反电动势观测、六步换相与 FOC。 结合 PWM、电流采样、波形调试理解模型误差。

最终只需要记住：电机最根本的电压方程是 u = Ri + dψ/dt。其它项都是在说明 ψ 从哪来、如何随时间变化。
