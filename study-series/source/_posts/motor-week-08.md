# W08 · 低速与零速：HFI 入门

**时间：** 2026-11-30—2026-12-06  
**方向：** 电机控制与嵌入式  
**时间预算：** 专业 45 分钟/日

## 本周目标

- 算法：凸极性、注入信号、解调、极性识别、声噪与转矩脉动
- 嵌入式：PWM/DMA 同步采集、带宽与数据记录
- 产出：HFI 原理图 + 低速方案评审
- 重点实验：在纸面或 Python 里分析注入频率、PWM 频率、采样率的约束

## 每日任务

- [ ] **2026-11-30 周一·理解**：先阅读「凸极性、注入信号、解调、极性识别、声噪与转矩脉动」，画知识关系图，写出 3 个待解决的问题
- [ ] **2026-12-01 周二·拆解**：推导/复盘关键公式与单位，指出 2 个前提假设；梳理「PWM/DMA 同步采集、带宽与数据记录」的工程约束
- [ ] **2026-12-02 周三·实现**：开展实际代码或 Python 仿真练习：在纸面或 Python 里分析注入频率、PWM 频率、采样率的约束
- [ ] **2026-12-03 周四·迁移**：对照 NXP 或 Infineon 参考工程/数据手册，记录入口函数、输入输出及差异
- [ ] **2026-12-04 周五·检验**：设计正常、边界、故障三个测试场景，并解释可能失败的原因
- [ ] **2026-12-05 周六·交付**：完成交付：HFI 原理图 + 低速方案评审；写清环境、步骤、输出、可复现实验
- [ ] **2026-12-06 周日·复盘**：口头用 2 分钟解释本周成果；回答 5 道自测题，整理未解决问题
