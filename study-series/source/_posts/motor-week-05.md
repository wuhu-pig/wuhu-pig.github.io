# W05 · 滑模观测器 SMO

**时间：** 2026-11-09—2026-11-15  
**方向：** 电机控制与嵌入式  
**时间预算：** 专业 45 分钟/日

## 本周目标

- 算法：滑模面、开关函数、反电动势重构、抖振与边界层
- 嵌入式：模块解耦、函数接口、观测器抽象与测试替身
- 产出：SMO 核心模块 + 两种观测器对照表
- 重点实验：实现 sat/tanh 边界层并比较抖振、延迟与噪声灵敏度

## 每日任务

- [ ] **2026-11-09 周一·理解**：先阅读「滑模面、开关函数、反电动势重构、抖振与边界层」，画知识关系图，写出 3 个待解决的问题
- [ ] **2026-11-10 周二·拆解**：推导/复盘关键公式与单位，指出 2 个前提假设；梳理「模块解耦、函数接口、观测器抽象与测试替身」的工程约束
- [ ] **2026-11-11 周三·实现**：开展实际代码或 Python 仿真练习：实现 sat/tanh 边界层并比较抖振、延迟与噪声灵敏度
- [ ] **2026-11-12 周四·迁移**：对照 NXP 或 Infineon 参考工程/数据手册，记录入口函数、输入输出及差异
- [ ] **2026-11-13 周五·检验**：设计正常、边界、故障三个测试场景，并解释可能失败的原因
- [ ] **2026-11-14 周六·交付**：完成交付：SMO 核心模块 + 两种观测器对照表；写清环境、步骤、输出、可复现实验
- [ ] **2026-11-15 周日·复盘**：口头用 2 分钟解释本周成果；回答 5 道自测题，整理未解决问题
