# W03 · 反电动势与信号处理

**时间：** 2026-10-26—2026-11-01  
**方向：** 电机控制与嵌入式  
**时间预算：** 专业 45 分钟/日

## 本周目标

- 算法：αβ 坐标下电压方程、反电动势与速度/角度关系
- 嵌入式：三相电流偏置、ADC 量化噪声、数字低通及延迟
- 产出：BEMF 估算仿真与滤波对照图
- 重点实验：用 Python 生成不同速度、噪声条件下的 eα/eβ；对比 LPF 相位延迟

## 每日任务

- [ ] **2026-10-26 周一·理解**：先阅读「αβ 坐标下电压方程、反电动势与速度/角度关系」，画知识关系图，写出 3 个待解决的问题
- [ ] **2026-10-27 周二·拆解**：推导/复盘关键公式与单位，指出 2 个前提假设；梳理「三相电流偏置、ADC 量化噪声、数字低通及延迟」的工程约束
- [ ] **2026-10-28 周三·实现**：开展实际代码或 Python 仿真练习：用 Python 生成不同速度、噪声条件下的 eα/eβ；对比 LPF 相位延迟
- [ ] **2026-10-29 周四·迁移**：对照 NXP 或 Infineon 参考工程/数据手册，记录入口函数、输入输出及差异
- [ ] **2026-10-30 周五·检验**：设计正常、边界、故障三个测试场景，并解释可能失败的原因
- [ ] **2026-10-31 周六·交付**：完成交付：BEMF 估算仿真与滤波对照图；写清环境、步骤、输出、可复现实验
- [ ] **2026-11-01 周日·复盘**：口头用 2 分钟解释本周成果；回答 5 道自测题，整理未解决问题
