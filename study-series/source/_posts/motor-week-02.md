# W02 · 电流环与定点数值实现

**时间：** 2026-10-19—2026-10-25  
**方向：** 电机控制与嵌入式  
**时间预算：** 专业 45 分钟/日

## 本周目标

- 算法：d-q 电压方程、PI 抗饱和、解耦、SVPWM 限幅
- 嵌入式：Q15/Q31 定标、乘法饱和、中间量位宽、C 单元测试
- 产出：离散 PI C 实现 + 单元测试
- 重点实验：以 Ts 参数化实现 PI；测试饱和、积分累积、输入阶跃与复位

## 每日任务

- [ ] **2026-10-19 周一·理解**：先阅读「d-q 电压方程、PI 抗饱和、解耦、SVPWM 限幅」，画知识关系图，写出 3 个待解决的问题
- [ ] **2026-10-20 周二·拆解**：推导/复盘关键公式与单位，指出 2 个前提假设；梳理「Q15/Q31 定标、乘法饱和、中间量位宽、C 单元测试」的工程约束
- [ ] **2026-10-21 周三·实现**：开展实际代码或 Python 仿真练习：以 Ts 参数化实现 PI；测试饱和、积分累积、输入阶跃与复位
- [ ] **2026-10-22 周四·迁移**：对照 NXP 或 Infineon 参考工程/数据手册，记录入口函数、输入输出及差异
- [ ] **2026-10-23 周五·检验**：设计正常、边界、故障三个测试场景，并解释可能失败的原因
- [ ] **2026-10-24 周六·交付**：完成交付：离散 PI C 实现 + 单元测试；写清环境、步骤、输出、可复现实验
- [ ] **2026-10-25 周日·复盘**：口头用 2 分钟解释本周成果；回答 5 道自测题，整理未解决问题
