02 · 需要真正掌握的知识

优先提升开口和连贯性。每周 10–12 个常用词块反复复述，不背长单词表；本周的表达素材：

  • field-oriented control
  • current loop
  • rotor position
  • back EMF
  • estimate
  • reference frame
  • feedback
  • sensorless
  • torque
  • speed

语法：比较级、因果表达 because/therefore/so。每个结构自己说出 5 个句子，再用于实际问答。

We estimate the rotor position using back EMF, but the signal becomes weak at low speed.

建议用 ChatGPT 语音模式练习两个场景：解释 FOC 流程；向同事说无感难点。听懂问题后先用短句回答，再补充 because / so / for example。
