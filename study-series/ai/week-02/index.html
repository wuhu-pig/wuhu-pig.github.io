结构化 JSON 与 Schema 验证

将审查内容变为能被脚本验证的数据

2026-10-19 — 2026-10-25每周 2h15m
本周交付 · 一个可以核对的成果

review_schema.json

本周只解决一个工程效率问题：将审查内容变为能被脚本验证的数据。不要为了完成任务就装一套大型平台；所有实验以模拟数据或已获准公开的数据为起点。

四次工作日程

周二 · 20 分钟

固定 severity、file、condition、evidence、test 字段

明确输入、目标和不能自动执行的操作

周四 · 25 分钟

设计必填、类型、未知字段拒绝规则

准备一份完全公开或合成的数据输入

周六 · 35 分钟

写 Python 校验器覆盖正常、缺字段、畸形 JSON

执行最小脚本或实验，保存原始输出

周日 · 55 分钟

将 3 份模型输出送入校验器

人工对照参考答案、统计缺陷、写一页报告

验收规则

人工可核对：所有异常格式被拒绝，人工可读证据保留。必须保留输入样本、模型/脚本输出、人工判定和失败样例；没有实际运行不得勾选完成。

职业关联与安全边界

  • 面向 C/MCU、SVN、需求追踪、测试、RAG、FreeMASTER 或受控 Agent 的具体岗位工作。
  • 禁止向未经授权的模型传输公司代码、客户要求或机密波形。
  • 默认只读；实际电机写参数、控制功率级需要专门人工授权和台架保护。

本周太累怎么办

只完成“准备一个样本 + 跑一次实验 + 用五句话判定结果”三步；周日可以减量至 20 分钟。不追逐 AI 工具数量。
