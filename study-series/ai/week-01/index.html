本周合成案例

#include <stdint.h>
uint16_t clamp_duty(int32_t duty) {
  if (duty > 1000) return 1000;
  return (uint16_t)duty;
}

合法输出为 0..1000；输入 -1 实际得到 65535。AI 应指出负数转换的风险，并给出 -1 / 500 / 1200 三组测试；单次命中不代表工具有效性已被证实。

验收规则

人工可核对：正确指出负数转 uint16_t 的问题，保留原始模型回答。必须保留输入样本、模型/脚本输出、人工判定和失败样例；没有实际运行不得勾选完成。

职业关联与安全边界

  • 面向 C/MCU、SVN、需求追踪、测试、RAG、FreeMASTER 或受控 Agent 的具体岗位工作。
  • 禁止向未经授权的模型传输公司代码、客户要求或机密波形。
  • 默认只读；实际电机写参数、控制功率级需要专门人工授权和台架保护。

本周太累怎么办

只完成“准备一个样本 + 跑一次实验 + 用五句话判定结果”三步；周日可以减量至 20 分钟。不追逐 AI 工具数量。
